# Proyecto Final Desarrollo Web 

#### Stack: PHP + Apache + MySQL + React

#### Setup Rapido:
```bash
git clone 

mv ~/xampp/htdocs # O la MAMP o donde se levante el servidor backend, despues levantas con XAMPP o MAMP el backend

cd ./SistemaControlPracticas/frontend/

pnpm install # O npm

npm run dev # Corre en el puerto 5173

```
